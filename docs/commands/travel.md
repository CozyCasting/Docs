# Travel Commands

Explore different fishing locations across the world. Higher-level locations offer better fish and rarer catches.

## /travel

Travel to a different fishing location.

- **Usage:** `/travel <region> <location>`
- **Aliases:** `ftravel`, `goto`
- **Examples:** `/travel NA river`, `/travel asia ocean`

Regions: `NA`, `Asia`, `Europe`. Each region has up to 9 location types (stream, pond, river, lake, ocean, deep sea, cave, volcano, arctic). Locations unlock as you level up.

## /location

View your current fishing location.

- **Usage:** `/location`
- **Aliases:** `loc`, `where`

Shows where you're currently fishing, including the location name, description, and available rarities.

## /locations

View all available fishing locations.

- **Usage:** `/locations`
- **Aliases:** `locs`, `regions`, `places`

Lists every location across all regions with level requirements and which ones you've unlocked. See the full [Locations Reference](../reference/locations.md) for details.
